Error messages without a designed UI

Every message the user can see that still appears as plain text — no card, no colour, no icon. Found by searching the whole app (src/) for status-bar errors, toasts, inline error labels and stock Qt prompts. Updated 15 Nov 2026.

Activation key — “Invalid activation key” Fixed in this build

The error under the key field was plain grey text: the card’s general label colour overrode its red. It now has its own design — a danger-tinted box, red text and a leading dot — in light and dark. The same fix applies to every card that has an input field.
