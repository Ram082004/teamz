UART Terminal workflow

How the tool behaves today, taken from uartterminalpanel.cpp and uartsession.cpp. Every design below must support each step here. Full write-up with line references: UART-Terminal-Workflow.md.

Main path

Open the tool

  • Tools strip → UART Terminal (or activity rail)
  • Single instance: if the tab exists it is focused
  • Opens as a tool tab in the PDF lane
mainapplication.cpp:8526

Find ports

  • Auto-rescan every 1 s, plus ⟳
  • Sorted COM2 → COM10, label COM5 · USB-SERIAL CH340
  • Last used port re-selected
  • None → "No serial ports found", Connect disabled
uartterminalpanel.cpp:665

Configure

  • Baud (19 presets, any value typed, default 115200)
  • Data 5–8 · Parity N/E/O/M/S · Stop 1/1.5/2
  • Flow None / RTS/CTS / XON/XOFF
  • Shown as 115200 8N1
uartterminalpanel.cpp:290

Connect

  • Opens port read/write, DTR + RTS released
  • "Connected to COM5 · 115200 8N1"
  • Button → red Disconnect, port picker locked
  • Port + settings saved
uartsession.cpp:135

Receive

  • Bytes queued, drawn every 30 ms
  • Text: UTF-8, ANSI stripped, CR/LF/CRLF = 1 break
  • Hex: 16 bytes/row · Mixed: hex + ASCII
  • Timestamps · Auto-scroll · Wrap
uartterminalpanel.cpp:822

Send

  • Enter / Send · ↑↓ history
  • Text + line ending (None/LF/CR/CRLF)
  • Hex 48 65 6C / 0x48,0x65 (no ending)
  • Repeat every N ms (payload frozen)
uartterminalpanel.cpp:1097

Inspect & keep

  • Find (Ctrl+F) · Clear (Ctrl+L)
  • Save… to .txt/.log
  • Log to file (live append)
  • RX/TX counters, LEDs, Reset
uartterminalpanel.cpp:1233

End

  • Disconnect → "Disconnected"
  • Unplug → "COM5 was disconnected."
  • Repeat stops, ports rescanned
  • Closing the tab closes the port
uartterminalpanel.cpp:775
